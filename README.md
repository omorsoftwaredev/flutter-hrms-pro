# Flutter HRMS Pro

A modern, scalable and production-ready **Human Resource Management System (HRMS)** built with **Flutter** and **Supabase**.

Designed for **Small, Medium and Enterprise Businesses** with a focus on:

- Clean Architecture
- Beautiful Material 3 UI
- High Performance
- Responsive Layout
- Cross Platform
- CodeCanyon Quality
